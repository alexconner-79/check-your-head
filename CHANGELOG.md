## 0.3.0 (2026-11-16)

- Added documentation for each skill, a contributing guide and a plugin icon

## 0.2.0 (2026-11-16)

- Split into six standalone skills, each with references, templates and a worked example
- Added tool routing for Figma, Jira, Linear, Notion, Confluence, Sheets, Slack, Mobbin, Claude Code and Claude Design
- design-sameness-check: code scan mode, tell list with code signals, ratings by area
- deceptive-pattern-pushback: Dark, Grey and Mistake classes, three tests, audit mode, AI and chatbot patterns, UK and EU regulatory reference
- heart-metrics-plan: guardrails, failure signal, instrumentation asks, proxies for teams without analytics
- design-decision-record: status values, superseding, guidance on what's worth recording
- ux-debt-entry: batch triage, interest column, WCAG and tracker priority mapping, CSV export
- design-impact-write-up: evidence ladder, wording for contribution versus attribution, case study format
